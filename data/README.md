# NexaTech GmbH Synthetic Workplace Dataset

Synthetic dataset for an enterprise Workplace Operations AI Agent / RAG + tool-calling portfolio project.

## Structured data
- employees.csv — 250 synthetic employees
- attendance.csv — synthetic weekday attendance records from 2026-01-01 to 2026-08-31
- leave.csv — synthetic vacation and sick-leave records
- holidays.csv — German public holidays used for the simulation

## Knowledge base
Markdown policy documents covering:
- attendance
- remote work
- leave
- working hours
- overtime
- sick leave

## Important
All employee identities, attendance records and company information are fictional and synthetic.
Do not treat the policies as real legal or HR advice.
